Responsive CSS Cheat Sheet

Quick reminders for building flexible webpages.

Responsive Design

Design pages that adapt to different screen sizes.

width: 100%;

Media Queries

Apply different styles when a screen reaches a breakpoint.

@media (max-width: 700px) { ... }

CSS Filters

Change the appearance of images with visual effects.

filter: grayscale(100%);

Typography

Use flexible text sizes to improve readability.

font-size: clamp(1rem, 2vw, 1.5rem);

CSS Grid

Make rows and columns for gallery or card layouts.

grid-template-columns: repeat(2, 1fr);

Flexbox

Align items in a row or column and control spacing.

display: flex;
