Understanding box-sizing

Compare how the same width behaves with padding.

content-box

Width: 260px
Padding: 24px
Border: 4px

With the default content-box, padding and border are added outside the set width. Total width is 260 + 48 + 8 = 316px.

border-box

Width: 260px
Padding: 24px
Border: 4px

With border-box, padding and border are included in the set width. The total width stays 260px.

Tip: many websites use box-sizing: border-box for easier sizing.
